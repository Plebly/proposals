# Proposal Tags

Tags make proposals easier to find. They are descriptive, not a review category or
an eligibility rule. Freeform tags are allowed; use short, lowercase terms and no
more than 12 tags per proposal.

## Suggested vocabulary

- `knots`
- `policy`
- `docs`
- `research`
- `tooling`
- `education`
- `lightning`
- `ui`
- `security`
- `commons`

Prefer an existing tag where it accurately describes the work. Add a new tag when
it gives donors and builders useful search context.

# Tooling starter

## Problem & audience

Describe the operational or developer workflow that is slow, unsafe, or unreliable. Identify the users and the Bitcoin software or data they work with.

## Plan & deliverables

- Publish source code in a public repository with an OSI-approved license.
- Provide reproducible build and test instructions.
- Document inputs, outputs, configuration, and failure modes.

## Verification

1. Clone the public repository at the submitted commit.
2. Run the documented build and test commands in a clean environment.
3. Exercise the documented example and confirm its expected output.

## Out of scope

Hosted operations, key custody, and integrations not explicitly named above.
